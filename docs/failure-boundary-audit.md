# 1.0 failure-boundary audit

Status: complete on 2026-09-20. Baseline:
`bada4ca docs: reconcile pre-freeze public interface inventory (#155)`.

This is a **non-normative evidence/navigation layer**. Semantics remain owned by
[`v3-public-interface.md`](v3-public-interface.md),
[`v3-architecture.md`](v3-architecture.md), and accepted ADRs. **Covered** means
a named test discriminates the boundary. **N/A** means the boundary cannot occur
by the owning contract. **Unsupported** means the owning authority explicitly
declines the stronger guarantee. There are no remaining **Material gap** cells.

ADR [0029](adr/0029-lifecycle-commits-complete-and-critical-sections-are-closed.md)
owns the deep lifecycle commit rule: cancellation before the irreversible commit
has no framework effect; cancellation after it abandons only the caller's wait
while framework-owned work reaches the documented barrier. Bounded test helpers
are hang guards, not ordering oracles.

## Complete boundary matrix

The matrix uses **Covered**, **N/A**, and **Unsupported** literally. A Covered
cell names both the owning authority and at least one discriminating test.
Cancellation cells name both sides of a commit when the operation has one.

- **PI-prep / PI-life / PI-effect / PI-service / PI-event / PI-observe /

## Cross-cutting conclusions

Operation-specific failures stay operation-specific; no global error was added.
Panic containment exists for Plugin apply, Event invocation/state factories,
Effect cleanup, Loader resolver, Runtime observers, Logger exporters, and
generation-owned task joins. Synchronous preparation contracts and caller-owned
`Timeout<F>` retain ordinary unwind.

Deep lifecycle and manual Effect claims use commit-aware cancellation;
Loader handoff has an analogous ownership transfer. Event and Timer futures keep
their own caller-owned semantics. Committed protocol truth survives origin
executor loss where promised; best-effort observation may be dropped.

Cross-task lifecycle self-wait is identified by allocation-based attribution and
returns the exact public `FiberId` plus `LifecycleOperation`. Cleanup belongs to
the generation whose open gate admitted the occurrence; cross-Fiber use does not
transfer that ownership, and spawn origin is provenance rather than parenthood.

## Gaps closed

The audit found **no supported-contract production defect**. It closed the
following evidence, authority, and discoverability gaps:

1. direct precommit-cancellation evidence for spawn, restart, Fiber disposal,
   and typed group removal;
2. direct origin-runtime-shutdown completion evidence for committed restart,
   update, era swap, Fiber disposal, group removal, spawn rollback, manual
   Effect disposal, and Loader handoff;
3. direct restart apply-panic, update-control panic, and postcommit update
   apply-panic regressions;
4. Event operation-future cancellation authority plus exact preclaim/postclaim
   once-occurrence evidence;
5. a discriminating Harness attempt-all teardown regression that forces one
   lifecycle-recursion refusal and still disposes the remaining Fiber;
6. explicit Loader-placement N/A and Timer caller-work panic classifications in
   the normative public interface;
7. a complete failure-boundary evidence matrix covering every required
   critical-path family; and
8. discoverable application teardown guidance grounded in the demonstrated
   Harness/Roster consumers.

No Runtime shutdown API, global error, ownership abstraction, Loader overlay
helper, or published-sibling seam redesign was introduced.
