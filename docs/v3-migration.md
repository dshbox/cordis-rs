# Cordis v3 migration inventory

**This document is optional and non-normative.** It records the complete
evidence and migration crosswalk for moving from the audited v2 Rust
interface to the approved Cordis v3 baseline, and it is never required
reading for that baseline. It owns exactly the non-normative residue of
the migration: v2 compatibility impact, implementation-only moves,
historical ADR provenance, the fixed 158-row invariant action/evidence
inventory with its concurrency, new-contract, and retirement indexes, and
the evidence-only artifact register. No v3 rule lives here, and no
statement in this document becomes normative by being stated here.

Every conclusion cited below has exactly one normative owner:
[CONTEXT.md](../CONTEXT.md) for canonical vocabulary,
[docs/v3-architecture.md](v3-architecture.md) for the target composition and
[the eleven ADRs](v3-architecture.md#decision-index) for hard-to-reverse decisions and their rationales,
[docs/v3-public-interface.md](v3-public-interface.md) for the exhaustive
caller-visible contract, and
[docs/v3-upstream-parity-ledger.md](v3-upstream-parity-ledger.md) for
upstream relationships against the exact pin. Audited v2 Rust source and
tests, historical ADRs 0001–0027, scratch tickets and maps, review
artifacts, and historical branches appear in this document only as
evidence.

This is the complete non-normative migration and test inventory. It assumes
the approved v3 architecture and public interface; it does not define either.
The audited v2 interface baseline came from the pre-promotion research repository at
Rust revision `2dda99f3d913a1410d1263aed8bd75d4e4dfb6f1`. The crate and example
sources were unchanged there through review revision
`592cb4af0e36b9c0d9df0265462c1cf4103ff10c`. Those research-repository
object IDs are historical evidence, not commits promised to exist in this
public repository.

In the tables below, **public break** means downstream source must change.
**Implementation-only** means the target behavior is unchanged at the public
seam and only private ownership, vocabulary, file placement, or test access
changes. V3 keeps no migration-only alias or second canonical path.

## Public compatibility crosswalk

### Crate and module paths

| Current v2 public path | Final v3 disposition | Concrete migration consequence |
| --- | --- | --- |
| `cordis_core::{context,effect,error,events,fiber,internal,list,logger,registry,service}` | Public modules are exactly `plugin`, `lifecycle`, `service`, singular `event`, `effect`, `logger`, and `observation`; `Context` and `BoxError` are root-only. | **Public break.** Imports move to semantic families. `context`, `error`, `events`, `fiber`, `internal`, `list`, and `registry` cease to be public paths; `effect`, `logger`, and `service` retain their semantic names but not their whole v2 contents. |
| All v2 `cordis_core` root re-exports | Replaced by the exact root whitelist `Context`, `Plugin`, `PreparedPlugin`, `PreparedChange`, `InjectSpec`, `FiberHandle`, `FiberId`, `FiberState`, `UpdateOutcome`, `Service`, `ConfigurableService`, `ServiceRealm`, `Event`, `Scope`, `Routing`, `QueryOutcome`, `Logger`, `Level`, and `BoxError`. | **Public break.** Any current root import not named here moves to its sole specialist path or disappears. No glob/prelude/compatibility facade survives. |
| Flat `cordis_loader` root | Public modules are `plan`, `resolver`, and `outcome`; its root whitelist is `EntryId`, `PluginEntry`, `EntryGroup`, `LoadPlanBuilder`, `LoadPlan`, `PluginResolver`, and `LoadOutcome`. | **Public break.** Specialist items use one module path; backing-tree and erased-adapter spellings disappear. |
| Flat `cordis_timer` root | Remains flat, containing exactly `TimerExt`, `Sleep`, `Timeout`, `TimeoutOutcome`, `Interval`, `TimerCancelled`, and `TimerRegistrationError`. | **Public break for changed/removed items**, otherwise a path-preserving rewrite. `ArmedSleep` is private and `Cancelled` is renamed/retyped. |

### Context construction and axes

| Current v2 public item(s) | Final v3 disposition | Concrete migration consequence |
| --- | --- | --- |
| `Context`, `Context::new`, `Clone` | Retain at crate root. `new` remains the only ordinary Runtime constructor and returns the root Context; clone preserves the exact view. | Source-compatible use continues. |
| `impl Default for Context` | Removed. | **Public break.** Call `Context::new()` explicitly. |
| `Context::root` | Retained; resets Fiber attribution, isolate, Scope, and intercept to the same Runtime's roots. | Calls remain but tests/callers must not assume it resets only isolation. |
| `IsolateId`, `IsolateId::GLOBAL`, `as_u64`, numeric/copy/order behavior | Removed from the public interface. | **Public break.** Numeric isolate inspection, global sentinel matching, ordering, serialization, and construction stop compiling. | `IsolateRealm::{Private, Shared(String)}` | Core policy enum removed. `ServiceRealm` is opaque, Runtime-local, non-constructible, `Debug + Clone + Eq + Hash`; Loader owns textual `RealmPolicy::{Private, Shared { label }}` per load execution. | **Public break.** Core callers allocate/map opaque realms; declarative label policy moves to Loader and has no cross-load stability. |
| `Context::with_isolated_service(name)` | Retained as isolate-only fresh-private-realm derivation. | Spelling remains; observable Scope advancement is removed. |
| `Context::with_isolate_realms(iter<(name, IsolateRealm)>) -> Context` | Replaced by `new_service_realm()` and fallible, atomic `with_service_realms(mappings)`, with `RealmMappingError::{DuplicateService, ForeignRealm}`. | **Public break.** Prepare opaque realms, then install one validated batch. | No v2 primitive child-Scope derivation; `EventCarrier::for_context` exposed the current position | Add `with_child_scope()` and `scope() -> Scope`; `Scope` is an opaque portable routing capability. | **New public contract.** Scope derivation is explicit and independent of isolation/intercept. |
| `Context::intercept(name) -> Option<InterceptConfig>` and private `with_intercept` machinery | Raw getter/storage become private. Public `with_intercept::<S>(S::Layer)` installs a prepared Service layer; `resolve_config::<S>` returns `S::Resolved` or `ConfigResolutionError`. | **Public break.** No `Any`/JSON readback. Source parsing/preparation happens before derivation; Service-owned composition runs outside locks. |

## Genuinely new v3 contract rows

V3 deliberately introduces **no structured ownership/lifetime abstraction**.
There is no `Lifetime`, `DisposalScope`, FiberGroup owner, stable seat,
parent-cascade, or Runtime shutdown to test. The affirmative ownership rows
are instead LF-09 through LF-12, EF-01/02/06/07, RG-01/04, ER-06/07, and
EX-01: generations own committed cleanup; Registry owns residency; consumers
own delivered FiberHandle composition.

| New contract cluster | Required observable result | Rows that carry the obligation |

| Commit-or-no-effect cancellation | Before each named irreversible commit, cancellation changes no framework state; after it, framework-owned work reaches the operation's documented barrier without caller polling. | LF-01/05/06/09/11, EF-02/07, RG-02/04, ER-06, LD-13, LK-04 |
