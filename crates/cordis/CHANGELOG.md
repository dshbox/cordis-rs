## [0.1.1] - 2026-08-16

### Fixed

- `block_on`: hold the Parker mutex while waking, closing a lost-wakeup window
  that could hang single-shot cross-thread wakes permanently
- fiber: fail fast on reentrant `restart()`/`dispose()` from lifecycle
  callbacks (status listeners, disposers) instead of deadlocking on the
  transition mutex
- events: evaluate user `ContextFilter`s outside the events state lock instead
  of deadlocking filters that re-enter the events API
- events: remove `once` listeners on invocation (upstream cordis parity);
  listeners skipped by an earlier bail or error stay registered
- registry: remove rejected plugin fibers from the registry so
  `len()`/`contains()` no longer report phantom records
- fiber: tolerate fibers that outlive their root context instead of panicking
- fiber: return an error from `update()` on the root fiber instead of
  panicking
- effect: close the `adopt()` check-then-act race that could leak a child's
  cleanup when the parent is disposed mid-adoption

### Performance

- fiber/reflect: dependency epochs are generation vectors aligned with inject
  order (no per-refresh string clones); `implementation_epoch` clones the
  service value only when an availability check exists; reconcile decides
  under one lock without cloning snapshots
- fiber: `update()` reuses its pre-validation result instead of validating the
  same config twice
- reflect: single-lock service lookups in `value()`/`set_value()`; availability
  predicates borrow via `downcast_ref`
- registry/reflect: service notifications use a per-service fiber index
  instead of scanning and upgrading every fiber in the registry
- logger: buffer stores `Arc<Message>` (cloning moves to read time); exporters
  iterate a registration snapshot; `Exporter::config_ref()` avoids deep-cloning
  level/formatter maps per message
- events: skip `internal/dispatch` meta-event construction when nobody listens

### Other

- `resolve_service_config` no longer requires `T: Clone` (semver-compatible
  relaxation)
- `Exporter` gained a default `config_ref()` method (non-breaking addition)

## [0.1.0] - 2026-08-16

### Added

- Initial release: a faithful, runtime-agnostic Rust port of the Cordis 4.x
  plugin framework core (the plugin framework at the core of DeepSeek
  Harness) — scoped dependency injection, lifecycle-owned effects, five-mode
  event dispatch, configuration interception, and structured logging, with
  zero external dependencies
